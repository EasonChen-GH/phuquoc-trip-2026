# 🌴 富國島 4D3N 奢華渡假 Web App (Phú Quốc Vacation Guide)

專為越南富國島（Phú Quốc）4天3夜自由行打造的「酷炫互動式旅遊隨身網頁 App」，包含行程時間軸、Google Maps 景點導航、即時越南盾與台幣匯率算盤、出國行李與證件檢查表、避雷指南。

---

## 🌟 核心功能

- **📅 4天3夜精華時間軸行程 (Day 1 - Day 4)**
  - **Day 1**：降落 PQC 機場 ➔ Check-in ➔ Chuon Chuon 半山腰高空酒吧夕陽 ➔ 陽東夜市美食大獵集 (炒冰、碳烤海鮮、炒花生)。
  - **Day 2**：世界最長跨海纜車 (Sun World Hon Thom) ➔ Aquatopia 水上樂園 ➔ 地中海「日落小鎮」 ➔ 親吻之橋 (Kiss Bridge) ➔ 海之吻水舞煙火秀。
  - **Day 3**：Vinpearl Safari 野生動物園（長頸鹿餐廳餵食） ➔ VinWonders 城堡水陸樂園 & 巨型海龜水族館 ➔ Grand World 竹之建築 ➔ 威尼斯運河貢多拉船 ➔ 威尼斯水上音樂燈光秀。
  - **Day 4**：Rạch Vẹm 海星沙灘 & 水上人家木棚海鮮 ➔ 富國特產巡禮 (胡椒/Sim酒/魚露) ➔ 越式草本泥浴 Spa 舒壓 ➔ 富國機場返台。
- **💱 越南盾 ↔ 台幣即時匯率算盤**：支援雙向動態心算法則（`去 3 個 0 × 1.3 ≈ NT$`），內建夜市海鮮、咖啡、纜車門票等消費預設按鈕。
- **📝 出國隨身行李檢查表**：支援點選勾選、進度條實時計算、100% 完成彩帶特效與手機自動存檔 (LocalStorage)。
- **🛡️ 富國島避雷指南**：免簽政策說明、Grab 叫車技巧、換錢與小費行情、220V 電壓與緊急救助電話。

## 🚀 本地開發與發佈

```bash
# 安裝依賴
npm install

# 啟動本地開發伺服器
npm run dev

# 打包生產版本
npm run build

# 一鍵發佈至 GitHub Pages
npm run deploy
```
